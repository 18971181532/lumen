网表语法

circuit   <title>
wavelength <nm>
source    laser in power=1 phase=0
wg        w1 in out length=100u neff=2.4 ng=4.2 loss=2
coupler   c1 in thru spare cross k=0.5 loss=0.1
atten     a1 in out loss=3
mzi       m1 in bar cross dL=20u k1=.5 k2=.5
ring      r1 in through add drop radius=10u k=0.2
monitor   m1 out
port      in
.sweep    1500 1600 0.25
.end

长度键 length / dl / radius / lam0 / arm 支持 SPICE 后缀：u n p m k。用户网名不能包含 @（保留给子电路内部节点）。

模型约定

元素模型
波导φ = 2π neffL/λ − phase；neff(λ) 线性色散，端点 ng
耦合器τ=√(1−K)，κ=√K，交叉项 +jκ，可选 excess loss
微环两只耦合器 + 两段 πR 弧，反馈由线性求解精确得到
MZI两只耦合器 + 两臂 L 与 L+ΔL
端口未连接端口视为匹配吸收；单模净最多两个端口
